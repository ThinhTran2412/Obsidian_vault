## 📸 Project: ShootMatch

**Chi tiết công việc:**
1. **Database:** Tạm biệt hoàn toàn cấu trúc lưu tạm `InMemoryRepositories`, chuyển đổi 8 kho lưu trữ dữ liệu sang hệ quản trị PostgreSQL bền vững bằng Entity Framework Core (chỉnh sửa DI từ Singleton thành Scoped services).

3. **Mobile Client:** Cập nhật UI và Logic cho app React Native. Thay đổi `AuthNavigator`, bổ sung màn hình chọn chức năng đăng nhập (`AuthMethodScreen`), màn hình `EmailLogin`, màn hình `Register`, và màn hình `PhoneLogin` (OTP). Khắc phục toàn bộ các lỗi liên quan đến TypeScript strict types để ứng dụng build thành công 100%.
