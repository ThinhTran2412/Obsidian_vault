## 🛠 Project: TCP Client-Server
**Mục tiêu:** Fix TCP Server Client Communication

**Chi tiết công việc:**
- Khắc phục sự cố ứng dụng bị treo (hang) sau khi client gửi lệnh lên server.
- Nguyên nhân: Client không phát hiện được điểm kết thúc của luồng dữ liệu JSON từ phía Server do cách server quản lý và ngắt kết nối (terminate connection).
- Giải pháp: Cập nhật logic đọc stream để đảm bảo client nhận đủ và parse chính xác JSON payload, sau đó đóng kết nối một cách an toàn và dứt khoát.
